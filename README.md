# Проектная работа Mesto

Mesto — это учебный проект от курса Яндекс Практикума «Ассоциированные программы: frontend-разработчик». Итоговым продуктом является сайт, где пользователи могут делиться фотографиями красивых мест и ставить лайки на карточки других пользователей.

## Функционал

- Изменение имени пользователя, описания профиля и аватара
- Добавление новых карточек в общую ленту
- Просмотр изображений карточек во весь экран
- Лайки карточек и просмотр их количества на каждой карточке
- Удаление своих карточек с подтверждением действия
- Пользовательская валидация всех полей ввода
- Просмотр статистики пользователей при нажатии на логотип сайта

## Технологии

- HTML, CSS (разметка и адаптивная вёрстка)
- JavaScript (функционал, валидация и работа с API)
- Vite (dev-сервер и сборка проекта)
- GitHub Pages (публикация сайта)

## Команды для сборки и публикации проекта

Запуск локального сервера:
```bash
npm run dev
```
Сборка проекта:
```bash
npm run build
```
Предпросмотр сборки проекта:
```bash
npm run preview
```
Публикация сайта на GitHub Pages:
```bash
npm run deploy
```
